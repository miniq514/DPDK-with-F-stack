## 1.0.1 范围 — 全链路 IPv6 统一

### 背景与目标

- 交换板 FPGA **仅 IPv6**；dac 与 fibre 若混用 IPv4/IPv6，脚本、`config.ini`、`demo_udp_config.h`、`peer/` 维护成本高。
- **1.0.1 目标：** `dac` / `fibre` **均使用 IPv6**；8007 收端地址 **统一为交换板要求的目的地址**；f0 **MAC 与 FPGA 一致**。
- **工作量评估：** 中等 — F-Stack 已支持 `config.ini` 的 `addr6` / `prefix_len`；主要改 bind、脚本、`ff_socket(AF_INET6)`、pktgen pcap 与文档，**不必改 io_uring 落盘层**。

### 统一地址规划（/64 同前缀）

| 角色 | 节点 | 接口 | IPv6 | UDP 端口 |
|------|------|------|------|----------|
| 收端 | **8007** | f0（fibre）/ f1（dac） | **`1111:2222:1111:2222:1111:2222:1111:0002`** | 8888（bind） |
| 发端 | 交换板 FPGA | — | `1111:2222:1111:2222:1111:2222:1111:0001` | 8888 |
| 发端 | **8004**（dac pktgen） | `enp66s0f1` | `1111:2222:1111:2222:1111:2222:1111:0003` | 8888 |

**约定：**

- 8007 **任意 `--link` 下收端 IPv6 均为 `…:0002`**（与 fibre/交换板 Dst_Address 相同）；同一时刻只启用 f0 或 f1 之一。
- **废弃** 联调用的 IPv4：`192.168.1.x`、`10.10.10.x`（代码与文档中移除或仅作历史说明）。

### 统一 MAC 规划

| 接口 | PCI | MAC | 说明 |
|------|-----|-----|------|
| f0 光口 | `42:00.0` | **`90:e2:ba:50:aa:70`** | **与交换板 Dst_Mac_Addr 一致**；`release_env.sh` / 联调前 `ip link set address` 保证一致 |
| f1 DAC | `42:00.1` | `90:e2:ba:50:aa:71` | dac 打流；pktgen pcap **DST MAC** 指向 f1 MAC |

若出厂 f0 已是 `aa:70`，脚本仍 **显式设置** MAC，避免重启/驱动恢复后偏离 FPGA 预期。

## 1.0.1 验收标准

| # | 场景 | 通过条件 |
|---|------|----------|
| V1 | **dac** 8004 → 8007 | pktgen IPv6 打流；`fstack_udp_recv --link dac --raw-payload` 落盘；verify 通过或 size/SHA256 符合预期 |
| V2 | **fibre** 交换板 → 8007 | 交换板发流；8007 `--link fibre` 收包落盘；无 IPv4 配置残留 |
| V3 | 配置一致性 | 代码/脚本/`config.*.ini` 中 **无** `192.168.1.x`、`10.10.10.x` 作为联调默认值 |
| V4 | MAC | f0 为 `90:e2:ba:50:aa:70`；F-Stack 启动日志 Port MAC 与预期一致 |
| V5 | release | Ctrl+C 后 `release_env.sh` 恢复 IPv6 + MAC，8004/8007 可 ping6（dac 同网段） |
| V6 | 发端 release | `sender/run_pktgen_sender.sh` 退出后自动还回 ixgbe、恢复 IPv6，无需手动释放 |
| V7 | payload 对齐 | 发端 pcap 与收端 raw 模式均按 1344B UDP payload（8B头 + 1336B体）口径一致 |

## 风险与依赖

| 风险 | 缓解 |
|------|------|
| F-Stack IPv6 UDP 与 IPv4 行为差异 | 先用 fibre 交换板验证；dac 用 peer IPv6 pcap 对照 |
| pktgen / gen_udp_pcap  IPv6 构造错误 | 用 `tcpdump -r` / `-e` 核对再上线速 |
| DPDK 占 vfio 后 `ip -6` 不可见 | 正常；仅 release 后用 tcpdump 排查 |
| 8007 f0/f1 同用 `…:0002` | **禁止同时 up 两条链路**；脚本 `--link` 互斥 |

## 建议实施顺序

```
1.0  dac IPv4 打通（可选捷径，验证 F-Stack + 落盘）
  ↓
1.0.1-A/C  配置 + 脚本 IPv6 + f0 MAC
  ↓
1.0.1-B    fstack_udp_recv AF_INET6
  ↓
1.0.1-D    peer IPv6 pcap → dac 回归
  ↓
1.0.1-E    fibre 交换板联调
  ↓
1.0.1 验收 V1–V5
```
