# Fstack-DPDk 设计文档

F-Stack UDP/TCP 收包迁移工程。**落盘（io_uring）不变**；UDP 可选 `--udp-bypass` 半旁路。  
**当前：V2.1 基本功能完成**（UDP/TCP + KNI）；V1.1 半旁路线速 ~9.4G；V2.2 多核发端为实验。  
**文档：** 8004 / 8007 同步（2026-07-14）。

**启动命令见 [../command.md](../command.md)。版本与缺口见 [迭代计划.md](./迭代计划.md)。**

## 版本路线

| 版本 | 状态 | 内容 |
|------|------|------|

## 网口（`--link` 切换）

| `--link` | 口 | 协议 | 典型收端 | 典型发端 | 用途 |
|----------|-----|------|----------|----------|------|
| `dac` | f1 | IPv6 | 8007 或 8004 | 对端 pktgen | 万兆 DAC 打流 |
| `fibre` | f0 | IPv6 | 8007 | 交换板 FPGA | 光口 raw 落盘 |

同一时刻只启用一条链路；pktgen 仅用于 `dac`。

## 约束

### `dac`

| 项 | 约定 |
|----|------|
| 协议 | IPv6 |
| 8007 地址 | `1111:2222:1111:2222:1111:2222:1111:0002/64` |
| 8004 地址 | `1111:2222:1111:2222:1111:2222:1111:0003/64` |
| UDP 端口 | 8888 |
| 目的 MAC | pktgen pcap DST = 收端 f1 MAC（8007 `aa:71`，8004 `7c:f9`） |
| 禁止 | `192.168.1.x`、`10.10.10.x` 作联调地址 |

### `fibre`（仅 8007）

| 项 | 约定 |
|----|------|
| 发端 | 交换板 FPGA `…:0001`，**不得**用 sender 代替 |
| 收端 | 8007 f0，`…:0002`，MAC `90:e2:ba:50:aa:70` |
| UDP | 8888，EtherType `0x86dd` |

#### 交换板 UDP 头（FPGA 参考）

| 字段 | 值 |
|------|-----|
| Dst_Mac_Addr | `90:e2:ba:50:aa:70` |
| Src_Mac_Addr | `11:11:11:11:11:11` |
| Src_Address | `1111:2222:1111:2222:1111:2222:1111:0001` |
| Dst_Address | `1111:2222:1111:2222:1111:2222:1111:0002` |
| Udp_Src/Dst_Port | 8888 |

## 数据流

**dac：**

```
8007/8004 pktgen ──IPv6 UDP:8888──► 对端 F-Stack (ff_recvfrom) ──► ring ──► writer ──► 落盘
```

**fibre：**

```
交换板 FPGA ──IPv6 UDP:8888──► 8007 f0 F-Stack ──► ring ──► writer ──► 落盘
```

## sender 工具包

目录 `sender/`：程序 A `gen_udp_pcap`（IPv6 pcap 生成）+ 程序 B `run_pktgen_sender.sh`（pktgen 打流）。

| 参数 | 说明 |
|------|------|
| `--to-8007` | dst `…:0002`，MAC `aa:71` |
| `--to-8004` | dst `…:0003`，MAC `7c:f9` |
| `--count N` | 与收端 `--expected-pkts` 一致 |
| `--rate-mbps` / `--rate` | 线路限速 |
| `--force-regen-pcap` | 改参数后重建 pcap |
| `NO_PROMPT=1` | SSH 自动化跳过确认 |

pcap 模板上限 5000 包，大数量靠循环；发端自动加余量防尾部截断。详见 [../command.md](../command.md)。
